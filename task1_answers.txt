Lab 4 - Task 1: Unification Queries
=====================================

?- house = house.
true.

?- house = abc.
false.

?- edge(a,b) = edge(C,b).
C = a.

?- edge(a,d) = edge(C,B).
C = a,
B = d.

?- edge(C,B) = edge(a,d).
C = a,
B = d.

?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g,h).

?- edge(A,A) = edge(b,c).
false.

?- edge(A,A) = edge(b,b).
A = b.

?- A = B, B = f.
A = f,
B = f.

?- A = B, B = f, A = e.
false.
